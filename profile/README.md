<a href="https://www.rriv.org">River Restoration Intelligence and Verification</a> (RRIV) provides environmental monitoring tools for the public good.

We build open source cloud services, configuration and control tools, and open hardware that empowers communities to monitor their own watersheds and supports R&D of novel sensor technologies. 

System documentation: https://rriv.gitbook.io/rriv-documentation/

Learn more: https://rriv.org
